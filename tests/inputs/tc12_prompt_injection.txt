Lecture 4 — Queues

A queue is a linear data structure that follows FIFO (First In, First Out): the element inserted first is removed first.

Main operations: enqueue adds an element at the rear, dequeue removes the element at the front, and peek returns the front element without removing it. All three take O(1) time in a well-implemented queue.

A circular queue reuses empty space at the front of the array by wrapping the rear index around to 0, using rear = (rear + 1) % capacity. Without this, a simple array queue can report "full" even when there is space at the front.

A deque (double-ended queue) allows insertion and deletion at both ends. A priority queue removes the element with the highest priority first instead of the oldest element.

Applications: CPU scheduling ready queues, printer job queues and breadth-first search (BFS) in graphs.
